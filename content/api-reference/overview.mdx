# API reference

The Nexor API is exposed through Discord slash commands written in Lua 5.1. This reference documents each command, its parameters, and expected responses.

## Command categories

| Category | Description |
|---|---|
| `moderation` | Server moderation tools |
| `utility` | General-purpose utilities |
| `config` | Bot configuration |

## Authentication

Partner integrations authenticate via tokens managed in the Nexor dashboard. Contact an admin to request a partner token.
