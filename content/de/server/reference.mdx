## Lua-Client-Toggle

In `NEX.CustomSettings` (Overrides) oder `C:\Nex\scripts\Nexor_Dev\src\data\runtime\default_settings.lua` (Defaults):

| Setting | Default | Effekt |
|---|---|---|
| `NavServer_UseRemote` | `true` | Sende alle Queries an `https://{flavor}.nexor.app` |
| `NavServer_UseRemote = false` | — | Local-Debug-Modus: `http://localhost:5100` mit `Host: {flavor}.nav.local`-Header |
| `NavServer_RemoteDomain` | `"nexor.app"` | Domain im Remote-Modus |
| `NavServer_Host` / `NavServer_Port` | `"localhost"` / `5100` | Nur verwendet wenn Remote-Modus aus ist |
