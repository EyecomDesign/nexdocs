# 🤖 Nexor

## Windows

1. Melde dich auf der Nexor-Website in deinem Konto an
2. Wechsle zum "Dashboard"-Tab
3. Klicke auf "Download für Windows"
4. Füge die heruntergeladene Datei in den NilName "scripts"-Ordner ein

## MacOS

1. Melde dich auf der Nexor-Website in deinem Konto an
2. Wechsle zum "Dashboard"-Tab
3. Klicke auf "Download für MacOS"
4. Füge die heruntergeladene Datei in den Tinkr "scripts"-Ordner ein
