# Zauberbücher

`NX.SpellBook:GetGlobal()` ist der normale Weg. Das globale Buch verbindet Klassen-
und Flavor-Katalog und löst Rangketten über Namen auf.

`NX.SpellBook:New()` und Registrierungshelfer sind für fortgeschrittene eigene
Zauberbücher. Sie sind sinnvoll für echte eigene Verhaltensweisen oder Aliase.
Keine IDs in die Rotation kopieren und generierte Katalogdateien nicht manuell
ändern.

Das einfache Warlock-Tutorial verwendet das globale Buch.
