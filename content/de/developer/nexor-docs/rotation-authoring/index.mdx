# Eine Rotation bauen

Dieser Kurs zeigt den Nexor-Standard für Rotationsdateien. Wir bauen eine kleine
Warlock-TBC-Levelingrotation für die Stufen 1–20. Sie ist ein Lehrbeispiel und
kein Plan für eine Migration bestehender Rotationen.

Der Kurs hat zwei Ebenen:

1. Kleine Lektionen erklären die Entscheidungen.
2. Die API-Seiten sind eine kurze, durchsuchbare Referenz.

Die vollständige, ladbare Quelle liegt in
[`Warlock_TBC_Authoring_Tutorial.lua`](https://github.com/NexorSystem/NexorBot/blob/Development/Rotations/ClassicTBC/WARLOCK/Warlock_TBC_Authoring_Tutorial.lua).
Spätere Lektionen lesen diese Datei direkt. So gibt es nur eine Quelle für das
Beispiel.

## Bewusst nicht enthalten

Dieses Beispiel migriert `Warlock_Leveling_TBC.lua` nicht, ändert keine Runtime,
implementiert keine Hunter-Logik und deckt Retail nicht ab. Eine neue Runtime-API
ist eine eigene Design- und Implementierungsaufgabe.

Beginne mit [Lektion 1](./course/01-environment) oder öffne die [API-Übersicht](./api).
