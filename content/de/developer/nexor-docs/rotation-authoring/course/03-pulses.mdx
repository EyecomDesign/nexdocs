# 3. Pulse und der erste Ladevorgang

Die Engine bildet Zustände auf Pulse ab. Eine Rotation muss
`EngagementPulse`, `CombatPulse` und `OutOfCombatPulse` anbieten.
`MultiPullPulse` ist optional und fällt ohne eigene Implementierung auf
`CombatPulse` zurück.

| Zustand | Pulse | Bedeutung |
| --- | --- | --- |
| Engage | `EngagementPulse` | Erstes Aktionsfenster öffnen. |
| Pulling oder Killing | `CombatPulse` | Normale Prioritätsleiter. |
| Moving, Waiting, Searching oder MapMovement | `OutOfCombatPulse` | OOC-Arbeit abarbeiten. |
| MultiPull | `MultiPullPulse` | Explizite Sammel-Policy der Rotation. |

## Vertrag für den OOC-Drain

`OutOfCombatPulse` gibt `true` zurück, solange Arbeit übrig ist, und `false`, wenn
alles erledigt ist. So weiß die Engine, ob sie weiter fragen soll. `nil` oder ein
ewiges `true` kann den Zustand festhalten.

Der erste ladbare Checkpoint ist bewusst klein:

```lua
local Rotation = {
    OutOfCombatPulse = function()
        if NX.Pet.Maintain() then
            return true
        end
        return false
    end,
    EngagementPulse = function() return false end,
    CombatPulse = function() return false end,
}

return Rotation
```
