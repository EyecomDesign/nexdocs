## Lua client toggle

Set in `NEX.CustomSettings` (overrides) or `C:\Nex\scripts\Nexor_Dev\src\data\runtime\default_settings.lua` (defaults):

| Setting | Default | Effect |
|---|---|---|
| `NavServer_UseRemote` | `true` | Send all queries to `https://{flavor}.nexor.app` |
| `NavServer_UseRemote = false` | — | Local-debug mode: `http://localhost:5100` with `Host: {flavor}.nav.local` header |
| `NavServer_RemoteDomain` | `"nexor.app"` | Domain used when remote mode is on |
| `NavServer_Host` / `NavServer_Port` | `"localhost"` / `5100` | Used only when remote mode is off |
