## SSH auf den VPS

Zwei User existieren auf `51.75.64.12`:

| User | sudo | docker-Gruppe | Wann verwenden |
|---|---|---|---|
| `ubuntu` | passwordless sudo | nein | Bootstrap, Datei-Installs in `/etc/*` / `/opt/*`, alles mit Root-Rechten |
| `deploy` | kein sudo | ja | `docker compose`-Befehle, Logs, App-Operations |

Beide haben den RSA-PEM-SSH-Key der Workstation (`~/.ssh/id_nexnav_deploy`) in ihren `authorized_keys`. Passwort-Auth ist deaktiviert.

```bash
# Privilegierte Operationen (Installs, sshd-Config, /etc/* Edits)
ssh -i ~/.ssh/id_nexnav_deploy ubuntu@51.75.64.12

# Tagesgeschäft mit Docker
ssh -i ~/.ssh/id_nexnav_deploy deploy@51.75.64.12
cd /opt/nexnav && docker compose ps
```

Falls du den privaten SSH-Key nicht hast, hol ihn aus dem Passwort-Manager des Operators. Der zugehörige Public-Key-Fingerabdruck ist `SHA256:c3CrFlQI39C4Hvea74lbJkOZzg6dx8XE5pJJHxlCA7I`.
