# Contribute to NexDocs

NexDocs publishes English documentation from `content/en/`. Start with
[Create a Page](/en/guides/creating-a-page) or
[Edit a Page](/en/guides/editing-a-page).

Use a branch and a pull request so content and its evidence can be reviewed.
Describe product behavior from the relevant source revision and verified release;
label source-only or pending behavior explicitly. A merged feature, an API
contract, or a screenshot from another version does not establish the installed
client's behavior. Capture screenshots only from a real, identified version and
remove account, member, and credential details.

Keep credentials, private operator identities, and environment inventory in the
authorized private process. Use placeholders and public-safe access instructions
in published pages and downloads. The retained `content-de-disabled/` tree is
unpublished; do not maintain it as a second locale.

The [validation commands](/en/guides/creating-a-page#validate-in-the-nexdocs-repository)
run in the **nexdocs repository root**. Rotation-authoring Python commands belong
to the **NexorBot repository root**; see
[lesson 27](/en/developer/rotations/rotation-authoring/course/27-audit-and-validation).
