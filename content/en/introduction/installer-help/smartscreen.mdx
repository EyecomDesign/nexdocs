# 🛡️ SmartScreen Warning

When you start the Nexor Installer for the first time, Windows may show a blue window that says
**"Windows protected your PC"**. This is Microsoft Defender SmartScreen. It shows for new programs
that are not code-signed yet. The Nexor Installer is new and not code-signed, so Windows does not
know it yet. The warning does not mean that the installer is harmful.

## How to start the installer

1. In the blue window, click **More info**.
2. Check that the app is **NexorInstaller-setup.exe**. The publisher shows as "Unknown publisher".
3. Click **Run anyway**.
4. The installer starts. It asks for no admin rights, because it installs only for your Windows user.

## Only run it from the Nexor website

Click **Run anyway** only for an installer you downloaded from the
[Download page](https://nexorapp.azurewebsites.net/download) of the Nexor website. If you got the
file anywhere else, delete it and download it again there.

## If Windows or your antivirus still blocks it

You can set up Nexor without the installer. Sign in on the Nexor website, open your
**Dashboard** and use the Bot download. It is a zip file with the Nexor loader and your personal
Key file. Unzip it into the `scripts` folder of NoName.
