# 🧰 Installer Help

The Nexor Installer sets up Nexor for you. It finds your NoName folder, signs you in, puts the
Nexor loader and your Key file in place, and prepares your WoW folders.

When something goes wrong, the installer shows a short message with a **How to fix** link. The
link opens the page below that matches the problem.

| Problem | Page |
|---|---|
| Windows shows "Windows protected your PC" | [SmartScreen warning](/en/introduction/installer-help/smartscreen) |
| The installer cannot find NoName, or NoName is not set up | [NoName not found](/en/introduction/installer-help/noname-not-found) |
| Sign-in does not work or has run out | [Sign-in problems](/en/introduction/installer-help/sign-in) |
| The Key file is missing or not valid | [Key file problems](/en/introduction/installer-help/key-file) |
| WoW folders are not found, or the Nexor assets do not install | [WoW folders and assets](/en/introduction/installer-help/assets) |
| A recommended addon does not install or remove | [Addons](/en/introduction/installer-help/addons) |
| Windows refuses to let the installer write a file | [Admin rights](/en/introduction/installer-help/admin-rights) |
| A download fails, or the installer asks for an update | [Downloads and updates](/en/introduction/installer-help/downloads-and-updates) |
| Play does not start NoName | [Starting NoName](/en/introduction/installer-help/starting-the-game) |

## First try Check & Repair

Open **Settings** (the gear in the sidebar), then **Check & Repair**. It checks every part of
your setup and fixes what it can. When the Main button in the sidebar says **Repair**, pressing it
does the same.

## Still stuck?

1. Open **Settings**, then **Advanced**, and click **Copy** next to the support info.
2. Open a ticket in the Nexor Discord (the Discord icon in the sidebar).
3. Paste the support info into your message. It holds no password and no key.
