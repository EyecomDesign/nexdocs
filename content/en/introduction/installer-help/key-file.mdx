# 📄 Key File Problems

Your **Key file** is your personal file that lets the Nexor bot sign in. The installer downloads
it from the Nexor website after you sign in and puts it into your NoName folder:
`scripts\Nexor_User\Authentication\Nexor.key`.

The installer refreshes the Key file each time it starts, so the bot keeps working.

## The Key file is missing

1. Make sure you are signed in (the account mark in the title bar).
2. Open **Settings → Check & Repair** and click **Repair**, or press the Main button when it
   says **Repair**. Repair downloads the Key file again.

## "The Key file from the website is not valid"

The website sent a Key file the installer could not read. Nothing was changed. Try again in a
few minutes. If it keeps happening, sign out, sign in again, and run Repair.

## The bot says the key is wrong

- Check on the website that your Nexor licence is active.
- Run Repair to get a fresh Key file.
- Do not copy `Nexor.key` from another PC or another account. Each Key file belongs to one
  account.
