# 🖥️ Helpcenter

Frequently asked questions.

<details>
<summary>Do I still need an unlocker?</summary>

Yes. Nexor requires the NilName unlocker for Windows.

</details>

<details>
<summary>Which unlockers are supported?</summary>

Nexor supports NilName on Windows.

</details>

<details>
<summary>Which client languages does Nexor support?</summary>

Set the game client to English for the best compatibility. Nexor also supports:

1. English
2. German
3. French

</details>

<details>
<summary>Does Nexor work on private servers?</summary>

No. Nexor works only on live servers.

</details>

<details>
<summary>Which payment methods are accepted?</summary>

We accept PayPal, credit cards, and cryptocurrency.

</details>

<details>
<summary>Are rotations or profiles included?</summary>

Yes. Nexor includes profiles for grinding from level 1 to 80 in WotLK and level 1 to 70 in Dragonflight. Questing is not included in these profiles. Basic rotations are included as well.

</details>

<details>
<summary>Why is my XP/H so low?</summary>

Check these points:

1. Upgrade your gear for your current level.
2. Learn the latest spells.
3. Buy health and mana potions and enable them in the **INVENTORY** settings.
4. Keep enough food and drinks for the bot.
5. Use larger bags for more items and loot.
6. Check that the character survives fights and is not dying often.

</details>

<details>
<summary>Is there an API for developers?</summary>

Yes. See the [Developer](/en/developer) section.

</details>

<details>
<summary>How can I add another session to NilName?</summary>

Create a separate NilName folder for each NilName token. If you run two bots, you need two Nexor sessions/tokens. You can use the same Nexor username for all licenses.

</details>

<details>
<summary>I have two or more bots. Do I need to run `nav.exe` again? (Windows)</summary>

No. Run `nav.exe` once per computer. This applies to Retail and Classic.

</details>

<details>
<summary>Why is my browser or antivirus blocking the download or files?</summary>

Game-hacking tools can trigger antivirus false positives because their behavior resembles malware or injectors.

If possible, use a separate machine for botting. On your main machine, add exceptions for the unlocker folder and its files. Temporarily disabling antivirus protection can also prevent interference, but an exclusion is the lasting setting.

</details>

</details>

<details>
<summary>Do I need to disable Windows Defender?</summary>

Create an exception or exclusion for Nexor in your antivirus and Windows Defender settings. Temporarily disabling protection is not the same as adding an exclusion.

[Add an exclusion to Windows Security](https://support.microsoft.com/en-us/windows/add-an-exclusion-to-windows-security-811816c0-4dfd-af4a-47e4-c301afe13b26)

</details>

<details>
<summary>My NilName license is invalid. What can I do?</summary>

Make sure the license file contains no spaces or empty lines.

</details>

<details>
<summary>My bot does not move and keeps trying to unstuck. What should I do?</summary>

Check the mmaps paths and download the mesh files from the [Windows installation guide](/en/introduction/getting-started/download-and-install/noname-windows) if needed.

For Classic, TBC, and WotLK, use:

`nn/mmaps/wotlk/FilesHere`

For Retail, use:

`nn/mmaps/sl/FilesHere`

Do not add another folder level, such as `mmaps/wotlk/wotlk`.

Also make sure `nav.exe` is running. If it closes, install or update the C++ redistributables and .NET Framework.

</details>
