# 🖥️ Helpcenter

Frequently asked questions.

<details>
<summary>Do I still need an unlocker?</summary>

The inspected v2 client loads through NilName/NoName. Confirm the current
release's exact game-build and unlocker requirements before obtaining access;
see [the unlocker guide](/en/introduction/getting-started/buy-unlocker/noname-windows).

</details>

<details>
<summary>Which unlockers are supported?</summary>

These guides describe the NilName/NoName Windows setup used by the inspected v2
client. Confirm the currently offered combination with
[official support](/en/introduction#discord-links). This is not a qualification
of other unlockers or platforms.

</details>

<details>
<summary>Which client languages does Nexor support?</summary>

Confirm the game-client language for your exact supported build with
[official support](/en/introduction#discord-links). NexDocs is published in
English; that does not establish a supported game-language list.

</details>

<details>
<summary>Does Nexor work on private servers?</summary>

Confirm the current live/private-server support policy with

</details>

<details>
<summary>Which payment methods are accepted?</summary>

Use the payment methods currently offered by the signed-in website's checkout.

</details>

<details>
<summary>Are rotations or profiles included?</summary>

Review the current product or plan offer for included profiles, rotations, and
any supported level range. Tutorial code or a source folder is not proof that
content is bundled with your license. Ask
[official support](/en/introduction#discord-links) if the offer is unclear.

</details>

<details>
<summary>Why is my XP/H so low?</summary>

Check these points:

1. Upgrade your gear for your current level.
2. Learn the latest spells.
3. Configure food, drinks and emergency items in [Settings → Recovery](/en/using-nexor/recovery).
4. Keep enough food and drinks for the bot.
5. Use larger bags for more items and loot.
6. Check that the character survives fights and is not dying often.

</details>

<details>
<summary>Is there an API for developers?</summary>

Yes. See the [Developer](/en/developer) section.

</details>

<details>
<summary>How can I add another session to NilName?</summary>

Follow NilName's current instructions for additional unlocker instances and
licenses. Nexor licensing is separate: two simultaneous bots need two NexorBot
licenses on your account.
The account's Connection Token or personal key file is a sign-in credential,
not an extra license. See [Account and Sessions](/en/introduction/getting-started/account-and-sessions).

</details>

<details>
<summary>Do multiple bots still need local navigation? (Windows)</summary>

Keep the local navigation helper required by your confirmed NilName release
available for Nexor's unlocker fallback. Follow the vendor's current instructions
for sharing a helper between instances. This is separate from the number of
[NexorBot licenses](/en/introduction/getting-started/account-and-sessions) needed.

</details>

exact file and version before changing security settings. This documentation
cannot establish that a blocked file is a false positive.

</details>

<details>
<summary>How does the session system work?</summary>

One NexorBot license permits one running bot. Two simultaneous bots require two
NexorBot licenses, on the same PC or different PCs. Optional products have their
own session limits. Pausing or stopping gameplay does not free the authenticated
session's licenses.

For an in-use license, an abandoned startup, a crash, or Connection Token renewal,
follow [Account and Sessions](/en/introduction/getting-started/account-and-sessions).
The guide explains **Active bot sessions**, **Kill Session**, **Kill all sessions**,
and the account-wide effect of **Renew Connection Token**.

</details>

<summary>Do I need to disable Windows Defender?</summary>

Follow the current vendor's verification and support instructions for your exact

</details>

<details>
<summary>My NilName license is invalid. What can I do?</summary>

Follow the current NilName release's license-file and recovery instructions from
its vendor. Do not share the file in a support report. For Nexor's own personal
key file, use [Account and Sessions](/en/introduction/getting-started/account-and-sessions);
the two credentials are separate.

</details>

<details>
<summary>My bot does not move and keeps trying to unstuck. What should I do?</summary>

Start with [World Map travel troubleshooting](/en/using-nexor/map-travel) and make a short [diagnostic report](/en/using-nexor/diagnostics).

Check the current build's map data, folder layout, and local navigation helper
using the [Windows installation guide](/en/introduction/getting-started/download-and-install/noname-windows)
and the vendor's confirmed instructions. Nexor can use remote navigation and an
unlocker fallback; keep the local helper available when relying on that fallback.
Do not use an old expansion-to-folder mapping as proof of compatibility.

</details>
