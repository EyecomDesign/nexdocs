# Getting Started

Follow this order to prepare an account, install the loader and check a first
session. Choose either a profile/routine for world automation or Rotation Mode
for playing the character yourself.

The release-specific support matrix and a fresh-client review of this
walkthrough are still pending in
[#15](https://github.com/EyecomDesign/nexdocs/issues/15) and
[#17](https://github.com/EyecomDesign/nexdocs/issues/17). Confirm the current
client build, platform, unlocker and available content with official support
before purchasing or installing. A flavor name or file in a repository is not
a support or bundled-content promise.

## Follow the setup path

1. **Confirm prerequisites.** Check the current compatibility with official
   support. The existing [unlocker guide](/en/introduction/getting-started/buy-unlocker)
   and [Windows installation guide](/en/introduction/getting-started/download-and-install/noname-windows)
   describe that setup path; verify their version-specific requirements for
   your installation. Rotation-only play and navigation profiles have different
   movement needs, explained in the first-run guide.
2. **Prepare a usable license.** Sign in to the
   [Nexor website](https://nexor.app/) and review the current
   [trial](/en/introduction/getting-started/get-trial) or
   [purchase](/en/introduction/getting-started/buy-nexor) options. Read
   [Account and Sessions](/en/introduction/getting-started/account-and-sessions)
   before starting a second bot or recovering an in-use license. A loader
   download does not itself grant a license.
3. **Download and install.** Follow
   [Nexor installation](/en/introduction/getting-started/download-and-install/nexor)
   for the mode your signed-in website offers. In personal-package mode,
   extract the loader and personal key file together into the unlocker's
   `scripts` folder, keeping the supplied structure. Keep the package private.
4. **Review product choices.** Open
   [Account → Products](https://nexor.app/dashboards/account/products) and read
   [Product loading](/en/introduction/getting-started/product-loading).
   Website choices concern a future startup. The current client can still
   present a separate product selector; check what actually loads.
5. **Launch and test deliberately.** Continue to
   [Your First Run](/en/introduction/getting-started/first-run) for account
   sign-in, rotation selection, one profile or routine, minimum supplies,
   start/pause/full stop and a complete Rotation Mode alternative.

## Use these account destinations

| Destination | Use it for |
| --- | --- |
| [Account → Overview](https://nexor.app/dashboards/account/overview) | Account credential mode and active bot sessions. |
| [Account → Bot Settings](https://nexor.app/dashboards/account/botsettings) | Bot license/session controls. |
| [Account → Products](https://nexor.app/dashboards/account/products) | Product ownership and saved character loading choices. |

For a refused startup, follow
[account/session recovery](/en/introduction/getting-started/account-and-sessions).
For a loaded bot that does not do the expected work, use the
[first-run checks](/en/introduction/getting-started/first-run#check-the-result)
and [diagnostics guide](/en/using-nexor/diagnostics).
