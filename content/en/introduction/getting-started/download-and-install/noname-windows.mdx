## 4. Start the applications [#4-start-the-applications]

<Callout type="error">
  The `.exe` files may be renamed, so their names may differ from the examples below.
</Callout>

Make sure both `Nav.exe` and `tool.exe` are present. If one is missing, your antivirus may have removed it as a false positive.

Add an antivirus exception for the applications, or temporarily disable the antivirus while you complete the setup.

Start `NoNameNavigation_RenameMe.exe`, then start `NnLoader_V1.8a.exe`. After both applications are running, open World of Warcraft.
