# 🔓 NilName (Windows)

These steps describe the NilName/NoName setup used by the inspected Nexor v2
client. Confirm the current release's supported game client/build and required
unlocker version with [official Nexor support](/en/introduction#discord-links)
before buying or installing. This page is not a confirmed support matrix.

**Official website:** [NilName](https://nilname.com/)

**Official Discord:** [NilName support](https://discord.gg/qXePhHsasJ)

## 1. Obtain the current vendor package [#1-pay--download-nilname-from-nilnamecom]

Follow the vendor's current account, purchase, download, and verification
instructions for the version Nexor support confirmed. Check the required
capabilities rather than assuming an old tier name or installer filename still
applies.

## 2. Prepare navigation for your build [#2-download-nilname--mmaps-files]

Obtain the map data and folder layout required by that unlocker release for your
exact game build. Use the vendor's current instructions and confirmed download
destinations; do not select an old mesh archive merely because its expansion
name resembles your client.

Nexor's inspected path router tries remote navigation and can fall back to the
unlocker's local path generator when that fallback is enabled. **Keep the
required local navigation helper and matching map data available for that
fallback.** A reachable remote service does not make local setup unnecessary.
If the local helper is unavailable, the client can temporarily skip that
fallback; restore the helper before relying on it again.

## 3. Install the required map data [#3-setup-the-mmaps-files-to-the-nilname-folder]

Extract the confirmed files into the layout specified by the current NilName
release. Check the directory depth and matching game build. This guide does not
certify a universal Retail/Classic/TBC folder mapping or a current third-party
archive; those need release-specific confirmation.

## 4. Start the vendor applications [#4-start-the-applications]

Start the unlocker and required navigation helper in the order documented by the
vendor for your release. Executable names can change. Check the current package
and vendor diagnostics instead of relying on historical screenshots or filenames.
If a file is missing or blocked, establish its current vendor verification and
support guidance before changing security settings.

## 5. Install Nexor [#5-you-are-ready-to-log-into-nexor-now]

[Continue with Nexor installation](/en/introduction/getting-started/download-and-install/nexor)
for the personal package and account/session recovery.
