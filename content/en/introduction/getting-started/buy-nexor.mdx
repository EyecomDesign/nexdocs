# 🛒 Buy Nexor

## Buy a NexorBot license [#how-to-buy-nexor-token-or-session]

1. Open the [Nexor website](https://nexor.app/) and sign in.
2. Confirm that the current release supports your exact game client/build and
   unlocker setup before buying a plan or account currency. Ask
   [official support](/en/introduction#discord-links) if this is unclear.
3. Read the current product offer: included products, license duration or usable
   time, price, and support terms. Check any trial and the payment methods actually
   offered by the current checkout.
4. Complete the purchase through the website's current purchase flow. A tutorial
   or source folder does not establish that its rotations, profiles, or level
   range are included in your plan.

## Run more than one bot

One NexorBot license permits one running bot. To run two bots at the same time,
buy two NexorBot licenses, whether they run on one computer or different computers.
Optional products have their own session limits; their licenses do not grant an
extra NexorBot session.

Your account's Connection Token or personal key file signs the bot in. It is
separate from a license. If a bot cannot start because a license is already in
use, follow [Account and Sessions](/en/introduction/getting-started/account-and-sessions)
to identify and end an old session before purchasing another license you may not
need.
