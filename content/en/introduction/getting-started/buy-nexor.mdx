# 🛒 Buy Nexor

## Buy a Nexor token or session [#how-to-buy-nexor-token-or-session]

1. Open the Nexor website.

2. Sign in with your Discord credentials.

3. Open the **Coin Market** tab and buy Nexor Coins.

4. Open the **Bot** tab.

5. Choose a plan.

## Add a session to your Nexor Account

You can add an extra session to each license. The rotations, profiles, and other premium features included with the license are available in that session. Use a session on another computer if needed; it does not have to run on the same computer as the license.
