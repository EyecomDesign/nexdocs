## What is Nexor? [#what-is-nexor]

Nexor provides Lua-based automation and rotation workflows for World of Warcraft.
The documentation covers tasks, profiles, rotations, and the services they use.
Which features and bundled content you can use depends on the current product
offer and release for your supported client.

Check the current offer before purchasing: confirm the exact game client/build,
platform and unlocker requirements, included products, and support terms.
Tutorial examples and source folders are not a list of officially supported
game versions. Ask in the [Nexor Discord server](#discord-links) when the current
offer or release notes do not establish your combination.

## Get Started

Follow the [ordered setup path](/en/introduction/getting-started), then use
[Your First Run](/en/introduction/getting-started/first-run) to check the loaded
rotation and profile/routine, or choose Rotation Mode.

If startup is refused or an old game window holds a license, use
[Account and Sessions](/en/introduction/getting-started/account-and-sessions)
to recover access and understand personal key files and Connection Token renewal.
Use [Choose Products](/en/introduction/getting-started/product-loading) to review a
character's website preferences and distinguish saved choices from loaded code.
