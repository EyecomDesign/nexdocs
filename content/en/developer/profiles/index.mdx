# Profiles

Profiles describe what Nexor should do in the world. Start with the Profile
Tool to capture a local route, then choose the runtime contract for your work.
Use task routines when profiles need a bounded stop gate or a quest sequence.

- [Profile Tool: capture, save and reopen](/en/developer/profiles/profile-tool)
- [Grinding and Gathering](/en/developer/profiles/grinding-gathering)
- [Questing Profiles](/en/developer/profiles/questing-profiles)

Grinding and Gathering have current loader, UI and runtime handlers. This
does not establish complete Fishing, Dungeon or Raid workflows from enum names
or template buttons alone.
