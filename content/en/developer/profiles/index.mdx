# Profiles

Profiles describe what Nexor should do in the world. Use questing profiles with
reusable task routines where appropriate.

- [Questing Profiles](./questing-profiles)

A profile that players load from the Library starts with a Meta block. See
[The Library](../library) for its fields, the categories and the author guidelines.

Dungeon, fishing, and gathering profiles are not part of the current public
profile authoring surface.
