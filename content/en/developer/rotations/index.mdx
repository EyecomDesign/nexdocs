# Rotations

Rotations define how Nexor combines the public `NX` API with a class-specific
priority policy. Keep API contracts in [NX API](/en/developer/api) and use this section for
the authoring workflow and complete examples.

## Rotation Authoring

The [Build a Rotation course](/en/developer/rotations/rotation-authoring) is the complete guide for
writing Nexor rotations. It covers the rotation environment, pulses, targets,
spells, pets, items, wands, and the read-only audit workflow.
