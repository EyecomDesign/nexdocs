# 2. Create the rotation file

Create one Lua file for your rotation in the user folder. For example:

```text
scripts/Nexor_User/Rotations/MyRotations/Warlock_TBC_Authoring_Tutorial.lua
```

Use a descriptive filename ending in `.lua`. Start with a new file instead of
copying a production rotation; the following lessons build the file in a
controlled order.

Next: [receive the rotation environment](./03-environment).
