# 9. Create live unit lookups

Keep live unit resolution in small helpers. Resolve the live player with
`NX.UnitManager.Get("player")` and the target with the same manager:

```lua
local function Player()
    return NX.UnitManager.Get("player")
end

local function Target()
    return NX.UnitManager.Get("target")
end

local function Pet()
    return NX.UnitManager.Get("pet")
end
```

Call these helpers when a pulse or predicate needs current state. Do not hold a
live wrapper as if it were a permanent snapshot.
