# 9. Define live unit locals

Resolve standard units once in the Unit definitions section:

```lua
local Player = NX.UnitManager.Get("player")
local Target = NX.UnitManager.Get("target")
local Pet    = NX.UnitManager.Get("pet")
```

These are self-refreshing wrappers. `Target` still follows the game's current
target after it changes, and a missing target or pet answers through the empty
`none` unit. Do not wrap each lookup in a `Player()` or `Target()` helper.
A position or health number read from a wrapper is a snapshot; read the method
again when a decision needs the current value.

Define a custom unit when the rotation selects a target itself. Its selector
returns a unit or `NX.UnitManager.Get("none")`, never `nil`. Define constants
and ordinary units above it, because the selector can run during file load.
Lesson 23 builds the tutorial's bounded DoT selectors.
