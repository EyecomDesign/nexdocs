# 15. Assign spell targets

Chain the target on the spell's condition. `Target` is the refreshing unit local
from lesson 9:

```lua
Corruption:CastableIf(function()
    return NX.Toggles["Damage"] and not Target:HasMyDebuff(Corruption)
end):SetTarget(Target)
```

This replaces the un-targeted attachment from lesson 14, rather than adding a
second condition. A resolver function is useful only when it must work out a
target at cast time. For a separate condition/target pair on one spell, use a
named `Behavior` and `Execute("Name")`; do not overwrite the default attachment.
The tutorial instead uses custom units for its different DoT targets.

`spell:Cast(target)` is a one-off full-gate cast that bypasses the attached
condition. Use `Execute()` in the normal ladder so its policy remains effective.
