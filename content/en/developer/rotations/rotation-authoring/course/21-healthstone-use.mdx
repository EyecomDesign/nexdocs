# 21. Create and use a Soulstone

Declare `CreateSoulstone` from the checked catalog and add a `Use Soulstone`
checkbox inside the Items option section. Its default is `true`. Attach creation
policy once:

```lua
CreateSoulstone:CastableIf(function()
    return NX.Options["Use Soulstone"] and not FindSoulstoneInBags()
end)
```

The item itself has no spell object carrying its use condition. Put that
condition in one Shared function, after the helpers from lesson 20:

```lua
local function UseSoulstoneOnPlayer()
    local soulstone = FindSoulstoneInBags()

    return soulstone
        and not HasAnySoulstoneBuff()
        and not Player:IsMoving()
        and NX.Spell.GetCooldownRemaining(soulstone.spellID) <= 0
        and NX.Item.UseItemByID(soulstone.itemID, "player")
end
```

The OOC pulse then contains the two simple steps:

```lua
if CreateSoulstone:Execute() then return true end
if NX.Options["Use Soulstone"] and UseSoulstoneOnPlayer() then return true end
```

Do not repeat the creation predicate around `Execute()`. The tutorial keeps the
item action out of combat. A rank not yet learned is refused by normal spell
gates; Soulstone creation begins at level 18 in this level-1–20 TBC example.
