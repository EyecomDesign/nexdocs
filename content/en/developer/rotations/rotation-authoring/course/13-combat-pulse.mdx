# 13. Implement the combat pulse

`CombatPulse` is the action window for the normal priority ladder. Add the
pause guard first:

```lua
CombatPulse = function()
    if NX.Toggles["Pause"] then
        return false
    end

    -- The priority ladder is added after spell policy is attached.
    return false
end
```
