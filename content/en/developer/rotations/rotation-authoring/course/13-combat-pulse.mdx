# 13. Implement the combat pulse

The normal combat priority ends after the first action that acts. It has no
pause guard and no final `return false`:

```lua
CombatPulse = function()
    NX.Wand.Maintain()

    if Corruption:Execute() then return true end
    if ShadowBolt:Execute() then return true end
end
```

returns early. Lesson 22 explains its framework ownership. Before adding spell
