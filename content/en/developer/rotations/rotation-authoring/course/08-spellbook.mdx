# 8. Load the global spellbook

Resolve the merged class and flavor catalog once near the top of the file:

```lua
local spells = NX.SpellBook:GetGlobal()

local DemonSkin       = spells.DemonSkin
local Corruption      = spells.Corruption
local CurseOfAgony    = spells.CurseOfAgony
local Immolate        = spells.Immolate
local ShadowBolt      = spells.ShadowBolt
local LifeTap         = spells.LifeTap
local HealthFunnel    = spells.HealthFunnel
local CreateSoulstone = spells.CreateSoulstone
```

Use catalog names instead of numeric spell IDs. The catalog handles rank and
flavor resolution; the later execute gate handles whether a learned spell can
actually be used.

Check the Warlock catalog for TBC and inherited Classic Era entries before
writing these locals. A catalog key exists even before the character learns a
rank; do not nil-guard a known catalog handle. Report a missing or incorrect key
rather than silently suppressing it. Spell options belong in the catalog, not
as rotation workarounds for an unverified rank or option.

Custom spellbooks are an advanced topic. Start with the global book and consult
the [spellbook API](../../../api/spellbooks) before registering custom handles.
