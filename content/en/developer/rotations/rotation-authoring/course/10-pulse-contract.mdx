# 10. Define the pulse contract

The returned rotation requires `Toggles` and `Options` tables and three pulse
functions. `MultiPullPulse` is optional and falls back to `CombatPulse`:

```lua
local Rotation = {
    Toggles = {},
    Options = {},
    OutOfCombatPulse = function() return false end,
    EngagementPulse = function() end,
    CombatPulse = function() end,
}
```

Only `OutOfCombatPulse` has a result the engine reads: return `true` for work
that acted and end with `return false`. Engagement, combat and multi-pull have
no final return. An early `if Spell:Execute() then return true end` still ends
one pulse after its first successful action; its boolean is not an engine
completion signal.
