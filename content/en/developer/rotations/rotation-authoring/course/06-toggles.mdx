# 6. Declare user toggles

Toggles switch broad categories while playing. This tutorial uses three:

```lua
Toggles = {
    ["Buffs"] = { Description = "Maintain self buffs", Default = true },
    ["Damage"] = { Description = "Use damage priorities", Default = true },
    ["Pet"] = { Description = "Manage the pet", Default = true },
}
```

Read `NX.Toggles["Damage"]` where the decision is made. A declared toggle has a
value; do not add `~= false`, a second defaults table or a wrapper function.
Check every read against the exact declared name: an unknown name reads `nil`
and should be caught during authoring.

The rotation window's pause button belongs to the framework, which suppresses
all pulses while paused. Do not declare a `Pause` toggle or repeat a pause guard
in the pulses. A single item gets an option such as `Use Soulstone`; a pulse
itself does not get a `Multipull` toggle. The bot's own setting decides whether
to gather multiple enemies.
