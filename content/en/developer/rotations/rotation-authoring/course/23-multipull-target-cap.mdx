# 23. Cap multipull targets

Make the target cap explicit when adding a multipull policy. A bounded selector
keeps the amount of work visible:

```lua
local MAX_MULTIPULL_TARGETS = 3

local function SelectMultipullTargets()
    local selected = {}
    NX.UnitManager.EnumActiveEnemies(function(enemy)
        if enemy:IsEnemy() then
            selected[#selected + 1] = enemy
        end
        return #selected >= MAX_MULTIPULL_TARGETS
    end)
    return selected
end
```

Returning `true` stops enumeration. Keep selection separate from the pulse that
uses the selected units.
