# 12. Implement the engagement pulse

`EngagementPulse` owns the opening priority after a target becomes relevant.
Use the same early-return action form as other pulses, without a final return:

```lua
EngagementPulse = function()
    if Corruption:Execute() then return true end
end
```

Attach Corruption's condition and target in the next lessons before using this
opening policy. The framework owns pause and cast gates. A selector that only
reads active enemies can miss a pull target that has not entered combat yet;
lesson 23 checks the current target before the active-enemy list.
