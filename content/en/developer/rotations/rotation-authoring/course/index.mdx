# Course

This course builds a small Warlock TBC leveling rotation one deliberate step at
a time. Each lesson has one job and leaves the file ready for the next lesson.

2. [Create the file](/en/developer/rotations/rotation-authoring/course/02-create-file)
3. [Receive the environment](/en/developer/rotations/rotation-authoring/course/03-environment)
4. [Define the file shape](/en/developer/rotations/rotation-authoring/course/04-file-shape)

Lesson 5 was removed because the unused rotation information table is ignored.
The later lesson numbers and URLs are preserved.
