# 11. Implement the out-of-combat pulse

Return `true` when an action actually acted, then finish with `false` when there
is no work. For the Demon Skin handle declared in lesson 8:

```lua
OutOfCombatPulse = function()
    if DemonSkin:Execute() then return true end
    return false
end
```

The framework already counts a running cast, channel or global cooldown as busy.
Do not return `true` merely because an action is desirable but cannot run yet;
that can prevent the bot from pulling or gathering forever. No pause guard is
needed because the framework does not dispatch pulses while paused.
