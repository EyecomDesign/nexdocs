# 19. Add class-specific pet policy

Class-specific decisions remain in the rotation. For a Warlock, Health Funnel
can use live player and pet state while the Pet Module remains generic:

```lua
HealthFunnel:CastableIf(function()
    local pet = NX.UnitManager.Get("pet")
    local player = NX.UnitManager.Get("player")
    return NX.Pet.IsPetActive()
        and (pet:GetHP() or 100) < 50
        and (player:GetHP() or 100) > 40
end)
HealthFunnel:SetTarget(function()
    return NX.UnitManager.Get("pet")
end)
```

The Warlock rotation owns the choice to spend health and mana. It should not
ask a generic pet helper to make that class decision.
