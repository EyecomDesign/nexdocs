# 16. Build the combat priority

Once policy and targets are attached, the pulse states the action order:

```lua
CombatPulse = function()
    NX.Wand.Maintain()

    if Corruption:Execute() then return true end
    if CurseOfAgony:Execute() then return true end
end
```

Keep the early returns on one line and group related actions with blank lines.
Do not repeat a spell's condition or mechanical gates in the pulse. There is no
final return because the engine discards the combat result.

The checked Warlock catalog supplies spell objects even before a rank is learned.
A misspelled/missing catalog key should fail clearly; do not hide it with nil
checks or an `Execute(spell)` wrapper. This checkpoint contains the two attached
