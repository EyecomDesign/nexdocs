# 1. Set up the rotation folders

Put your own rotation under `scripts/Nexor_User/Rotations/`. You can use any
subfolders:

```text
scripts/Nexor_User/Rotations/
└── MyRotations/
```

Folder names carry no meaning. The game version and the class a rotation is for come
from its [Meta block](/en/developer/library), not from a folder named `TBC` or
`WARLOCK`. Only three folder rules exist: `Drafts` is never delivered, a folder
starting with `_` holds internal helpers, and a folder starting with `@` holds shared
helpers. No rotation file name starts with `_` or `@`.

The course's reference source lives in the NexorBot repository at
`Rotations/TBC/WARLOCK/Warlock_TBC_Authoring_Tutorial.lua`. Copy it into your user
folder to test it locally.
