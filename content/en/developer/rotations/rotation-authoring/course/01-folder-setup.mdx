# 1. Set up the rotation folders

Create the rotation inside the loader-owned `Rotations` tree in the NexorBot
repository. Use one folder for the expansion and one for the class:

```text
Rotations/
└── ClassicTBC/
    └── WARLOCK/
```

Keep rotation source files in this tree. `Profiles/` contains profile data and
`NexDocs/` contains documentation; neither is a rotation load location.

Next: [create the rotation file](./02-create-file).
