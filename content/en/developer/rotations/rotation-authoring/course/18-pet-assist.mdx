# 18. Add pet combat assist

Keep the top-level `local PetModule = NX.Import("PetModule")` from lesson 17.
Write the assist call directly at the desired place in engagement/combat policy:

```lua
EngagementPulse = function()
    if NX.Toggles["Pet"] and PetModule.Assist() then return true end

    if Corruption:Execute() then return true end
end
```

There is no one-use `AssistPetInCombat` wrapper or final return. Placement within
its supported pulse is the author's choice. The tutorial heals with Health
Funnel before Assist in combat. The explicit Pet guard makes this tutorial's
switch apply to the action call as well as the module's stance lifecycle.
