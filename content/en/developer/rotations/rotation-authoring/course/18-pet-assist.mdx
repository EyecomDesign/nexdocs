# 18. Add pet combat assist

Keep the top-level `local PetModule = NX.Import("PetModule")` from lesson 17.
Use a separate helper for the pet's normal combat assist intent:

```lua
local function AssistPetInCombat()
    return NX.Toggles["Pet"] and PetModule.Assist()
end

EngagementPulse = function()
    if AssistPetInCombat() then
        return true
    end
    return false
end
```

Call assist from the engagement or combat path when the rotation wants the pet
to act. Do not turn generic assist into a class-specific healing decision.
Manual commands remain on `NX.Pet`; module actions come from `PetModule`.
