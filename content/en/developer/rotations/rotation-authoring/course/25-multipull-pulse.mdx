# 25. Wire the multipull pulse

The custom units already own target selection and their spells already own
Damage policy. The pulse simply states the two actions:

```lua
MultiPullPulse = function()
    if Corruption:Execute() then return true end
    if CurseOfAgony:Execute() then return true end
end
```

No separate Multipull toggle switches this pulse. The bot's gathering setting
owns whether it gathers several enemies. Without `MultiPullPulse`, the framework
runs `CombatPulse` instead; keep this optional override only when its action
order should differ. There is no final return or pet gather wrapper.
