# NX API

This section is the inventory of the public objects and functions exposed to a
Nexor rotation through the `NX` scope. Use the pages below as the searchable
reference; the rotation course explains how to combine the same contracts.

## Public NX objects

| NX object | Covers | Reference |
| --- | --- | --- |
| `NX.UnitManager` | Live unit wrappers and bounded selectors | [Units and targets](./units-and-targets) |
| `NX.SpellBook` | Global and custom spellbooks | [Spellbooks](./spellbooks) |
| `NX.Item` | Item counts, use, and item policy | [Items, wands, and settings](./items-wands-settings) |
| `NX.Pet` | Pet state, maintenance, and commands | [Pets](./pets) |
| `NX.Combat` | Combat service exposed to the rotation environment | [Environment](./environment) |
| `NX.Movement` | Paths, movement styles, and route ownership | [Movement](./movement) |
| `NX.Wand` | Framework-owned wand maintenance intent | [Items, wands, and settings](./items-wands-settings) |
| `NX.Toggles` | Live user toggle values | [Environment](./environment) |
| `NX.Options` | Live user option values | [Environment](./environment) |
| `NX.Player` | Player class description, not a live unit wrapper | [Units and targets](./units-and-targets) |

## Rotation entry points

These functions are fields on the rotation table rather than methods on an NX
object:

| Function | Purpose | Reference |
| --- | --- | --- |
| `EngagementPulse` | Prepare the next engagement action | [Pulses](./pulses) |
| `CombatPulse` | Run the combat priority ladder | [Pulses](./pulses) |
| `OutOfCombatPulse` | Drain out-of-combat work | [Pulses](./pulses) |
| `MultiPullPulse` | Optional multi-target combat policy | [Pulses](./pulses) |

The authoritative declarations are in
[`Public/RotationAPIs.lua`](https://github.com/NexorSystem/NexorBot/blob/Development/Public/RotationAPIs.lua).
The course adds authoring patterns around those declarations; it does not create
a second runtime API.
