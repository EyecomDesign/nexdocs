# NX API

Every rotation, profile, quest-step custom-code callback and plugin receives
the same public `NX` table. Start with [Environment](/en/developer/api/environment) for the
entry header, script return values and event lifetime. The rotation course
combines the same contracts into a rotation.

## Public NX objects

| NX object | Covers | Reference |
| --- | --- | --- |
| `NX.UnitManager` | Live unit wrappers and bounded selectors | [Units and targets](/en/developer/api/units-and-targets) |
| `NX.SpellBook` | Global and custom spellbooks | [Spellbooks](/en/developer/api/spellbooks) |
| `NX.Item` | Item counts, use, and item policy | [Items, wands, and settings](/en/developer/api/items-wands-settings) |
| `NX.Pet` | Basic pet state and manual commands | [Pets](/en/developer/api/pets) |
| `NX.Combat` | Public combat helpers | [Environment](/en/developer/api/environment) |
| `NX.Movement` | Paths, movement styles, and route ownership | [Movement](/en/developer/api/movement) |
| `NX.Wand` | Framework-owned wand maintenance intent | [Items, wands, and settings](/en/developer/api/items-wands-settings) |
| `NX.Toggles` | Live user toggle values | [Environment](/en/developer/api/environment) |
| `NX.Options` | Live user option values | [Environment](/en/developer/api/environment) |
| `NX.Spell` | Spell functions by ID and spell-object construction | [Spells](/en/developer/api/spells) |
| `NX.Events` | Script-owned event listeners and cleanup | [Environment](/en/developer/api/environment#event-ownership-and-cleanup) |
| `NX.Quest` | Quest state checks in every script kind | [Environment](/en/developer/api/environment) |
| `NX.Distance` | Plain distance functions | [Environment](/en/developer/api/environment) |

## Rotation entry points

These functions are fields on the rotation table rather than methods on an NX
object:

| Function | Purpose | Reference |
| --- | --- | --- |
| `EngagementPulse` | Prepare the next engagement action | [Pulses](/en/developer/api/pulses) |
| `CombatPulse` | Run the combat priority ladder | [Pulses](/en/developer/api/pulses) |
| `OutOfCombatPulse` | Drain out-of-combat work | [Pulses](/en/developer/api/pulses) |
| `MultiPullPulse` | Optional multi-target combat policy | [Pulses](/en/developer/api/pulses) |

The authoritative declarations are in
[`Public/PublicAPIs.lua`](https://github.com/NexorSystem/NexorBot/blob/9f373eaa9bd3d65581fc5ad6c52a417b87c71a89/Public/PublicAPIs.lua).
The course adds authoring patterns around those declarations; it does not create
a second runtime API.

This reference follows the merged shared-NX baseline in that revision.
[Optional imports](/en/developer/api/pets) are tracked by [#10](https://github.com/EyecomDesign/nexdocs/issues/10).
The later namespace regrouping remains in [#12](https://github.com/EyecomDesign/nexdocs/issues/12);
use the names verified here until its runtime changes are released.
