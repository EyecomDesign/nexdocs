# Product configuration: profile files

In `nexor-config.json`, the content type for a profile file is the singular
`profile`. The type tells the website and bot what kind of content an entry
contains; `src` is the repository file path.

For example, put this entry in the `contents` list of your existing product or
module, keeping the surrounding configuration:

```json
{ "type": "profile", "src": "profiles/farm.lua" }
```

This is one content entry, not a complete product configuration. The file must
exist at the path in your repository. The folder in this example is still named
`profiles`: changing a **type value** does not rename a folder, file or product.

## Updating an existing config

Replace `"type": "profiles"` with `"type": "profile"` in every affected content
entry, including entries inside modules. Leave `src` paths unchanged. For
example, `profiles/farm.lua` stays `profiles/farm.lua`.

After the website's singular-type change, adding or syncing a repository whose
config still uses the plural type is refused with:

> Content type 'profiles' was renamed to 'profile'.

Fix the type values, commit the updated config in your repository and sync
again. A refused sync leaves the previously published version live; it does
not publish the invalid config. Translation of older stored/published data is
handled by the server and does not make the old spelling valid in a new sync.
