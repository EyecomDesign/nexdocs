# Developer

The Developer area documents the public interfaces and authoring workflows for
Nexor extensions.

- [API](./api) — browse the objects and functions exposed through `NX`.
- [Profiles](./profiles) — create and organize questing profiles.
- [Product configuration](./products/configuration) — use the singular `profile` content type and update an older config.
- [Rotations](./rotations) — build class rotations one step at a time.
- [Tasks](./tasks) — use reusable task routines.
