# Developer

The Developer area documents the public interfaces and authoring workflows for
Nexor extensions.

- [API](/en/developer/api) — browse the objects and functions exposed through `NX`.
- [Profiles](/en/developer/profiles) — create and organize questing profiles.
- [Product configuration](/en/developer/products/configuration) — use the singular `profile` content type and update an older config.
- [Rotations](/en/developer/rotations) — build class rotations one step at a time.
- [Tasks](/en/developer/tasks) — use reusable task routines.
