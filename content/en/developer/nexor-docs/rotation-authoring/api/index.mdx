# API map

The course is the detailed path. These pages are the short navigation layer for
the public rotation API.

| Need | Page |
| --- | --- |
| Environment services and live player lookup | [Environment](./environment) |
| Unit wrappers and selectors | [Units and targets](./units-and-targets) |
| Pulse names and return values | [Pulses](./pulses) |
| Spell attachments and execution | [Spells](./spells) |
| Global and custom spellbooks | [Spellbooks](./spellbooks) |
| Pet ownership and commands | [Pets](./pets) |
| Items, wands, and settings | [Items, wands, and settings](./items-wands-settings) |
| Custom paths and movement ownership | [Movement](./movement) |

The authoritative declarations are in
[`Public/RotationAPIs.lua`](https://github.com/NexorSystem/NexorBot/blob/Development/Public/RotationAPIs.lua).
The course adds authoring patterns around those declarations; it does not create
a second runtime API.
