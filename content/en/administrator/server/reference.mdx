# 📑 Reference

This reference explains the public concepts used by the operations guides.
Request current environment details through
[Access](/en/administrator/server/access).

## Terminology

| Term | Meaning |
| --- | --- |
| Navigation service | The service that calculates walking routes for a requested map and game flavor. |
| World API | The service that supplies world records; its data and moderation workflow are separate from walking-path calculation. |
| Origin | The underlying service destination; its private address is not a public access instruction. |
| Release revision | The source or artifact identifier needed to connect an observation to a deployment. |
| Dataset | The map or world data qualified for a particular flavor and format. |
| Health check | One service observation; a representative customer operation is still required after a release. |
| Private runbook | Owner-approved operational instructions containing environment-specific details and access references. |

## Public-safe examples

Use explicit placeholders when an example needs a destination:

| Example | Purpose |
| --- | --- |
| `https://navigation.example.invalid` | Illustrative service URL, not a running Nexor endpoint. |
| `<environment>` | Environment selected by the authorized operator. |
| `<release-revision>` | Revision to verify against the deployment record. |
| `<credential-reference>` | Reference in the approved private store, never a credential value. |

A placeholder is not an instruction to reuse an old value from this repository's
history. Obtain the current approved configuration from the service owner.

## Keep environment inventory private

Current host addresses, administrator accounts, filesystem layouts, certificate
inventory, network rules, account identifiers, container pins and resource
budgets belong in the private deployment record. Include public-safe identifiers
in an incident report only when the owner has approved their disclosure.

Do not treat this site, a public issue or a search index as a secret store. If a
credential has been published, follow the private assessment and rotation process
in [Operations](/en/administrator/server/operations).
