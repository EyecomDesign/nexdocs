# Administrator

The Administrator area contains operational documentation for Discord, the
server, TrinityCore map files, and World API.

- [Server](/en/administrator/server/overview) — operate the NexNavigation service.
- [TrinityCore MMAP Files](/en/administrator/trinitycore-mmap-export) — build and export map data.
- [World API](/en/administrator/world-api/overview) — manage world data and the admin area.
