Visit the Nexor website to download your copy of Nexor.

## 4.) Setting up the files!

<Callout type="error">
  **Important!**

  Pay close attention to precise file paths. For macOS users, exclusively utilize `.luac` files from the Nexor download!

  **a)** Insert your `_NEXOR.luac` file into `tinkr/scripts/NEXOR` folder!

  **b)** Copy and paste your downloaded and extracted `.mmap` files into the appropriate folder.
</Callout>

### a) Nexor script file

Place the `_NEXOR.luac` file in the correct Tinkr scripts folder.
