# Markdown basics

This page shows common Markdown patterns you can use in `.mdx` files.

## Headings

Use `#` through `######` for six levels of headings. Keep a clear hierarchy on each page.

## Emphasis and inline code

You can use **bold**, _italic_, **_bold italic_**, and `inline code` for APIs, file names, and short snippets.

## Lists

Unordered:

- First item
- Second item
  - Nested item

Ordered:

1. Step one
2. Step two

## Blockquote

> Use blockquotes for citations, important notes, or quoted text.

## Links

External link: [Nextra documentation](https://nextra.site/).

## Tables

| Feature   | Supported |
| --------- | --------- |
| Headings  | Yes       |
| Tables    | Yes       |
| Task list | Optional  |

## Horizontal rule

---

Use a horizontal rule to separate major sections when it helps readability.
