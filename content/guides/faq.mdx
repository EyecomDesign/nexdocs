# Frequently Asked Questions

## General

### What is Nexor?

Nexor is a Lua-based Discord bot designed for server management, automation, and custom commands. It runs on Lua 5.1 and is fully scriptable.

### Is Nexor free to use?

Nexor has a free tier that covers core features. Partner access unlocks advanced commands and priority support.

### Which Discord servers can use Nexor?

Any Discord server where you hold Administrator permissions can invite Nexor. There are no restrictions on server size.

---

## Setup

### How do I invite Nexor to my server?

Visit the Nexor bot page and click **Invite**. Choose your server from the dropdown, then approve the requested permissions. See the [Getting Started](/guides/getting-started) guide for a full walkthrough.

### Nexor joined but isn't responding — what's wrong?

Check the following:

1. Nexor has **Send Messages** and **Read Message History** permissions in the channel.
2. You are using the correct command prefix (default: `/`).
3. The bot is shown as **Online** in the member list.

---

## Commands

### How do I see all available commands?

Run `/help` in any channel where Nexor has access. This lists every command your role can use.

### Can I create custom commands?

Yes. Admins can define custom Lua scripts via `/script add`. See the [API Reference](/api-reference/overview) for the full scripting API.

---

## Troubleshooting

### Nexor left my server unexpectedly

Nexor may have been removed by another administrator, or the bot may have been offline during a server outage. Re-invite it using the standard invite link.

### I found a bug — where do I report it?

Open an issue in the [GitHub repository](https://github.com/EyecomDesign/nexdocs) or contact support through the partner portal.
